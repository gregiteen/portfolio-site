## Modules
- `scripts/lib/site-mode.mjs` (new, testable): `generationEnabled`, `isPrivatePath`, `proxyJsn`. `serve.mjs` only wires it in (A-012).
- **Public vs private (A-015):** with generation off, `isPublicPath` is true for everything except `isPrivatePath` (`/crm-app.html`, `/jobs*`). Admin APIs keep their own `isAdmin` checks.
- **Generation off (A-016):** `requestGeneration` is a no-op with a warning; `/generate-theme` → 410; `/generate-status` → `{status:'disabled'}`; `/generate.html` → 302 `/`; `getLatestSkinBase()` → null so no skin redirects; `splash.html` for a signed-in user → `/`; `verify.html` treats `disabled` as ready and continues to `next` or `/`. `build-site.mjs` does not inject the flipper or generator script when the flag is off (to do).
- **JSN frontend:** `static/jobs.html|js|css` are generated by `npm run sync-jobs` from the JSN repo's `public/` (`JSN_REPO`), with `window.JSN_API_BASE='/api/jsn'` so the same code works in both places. One source, no fork.
- **Proxy:** only `/api/[a-z0-9/_-]+`, GET/POST/PUT/PATCH/DELETE, 1 MB body cap, 15 s timeout, no cookies forwarded, JSON passed through with status; 503 with a clear message when `JSN_URL` or `JSN_API_TOKEN` is unset, 502 when JSN is unreachable.
- **JSN side:** binds loopback by default; with `JSN_HOST` on a mesh address it refuses to start without `JSN_API_TOKEN` and requires `Authorization: Bearer` on `/api/*`. The token is a Total Recall secret bound to both repos.
- **Identity (A-008):** one source, `ADMIN_EMAIL`/`MAIL_FROM`, default `me@gregiteen.xyz`; the hardcoded literals are replaced.
- **Cookie (A-007):** `gi_auth` gets `Secure` when the request is HTTPS (via `X-Forwarded-Proto` or `SITE_URL`).
- **AI calls (A-003):** enrichment moves to `lib/openrouter.mjs`; the runtime `apiKey` setter in `/api/admin/settings` is removed; one-off `gen-*.mjs` scripts are deleted.
