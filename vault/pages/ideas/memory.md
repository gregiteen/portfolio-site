Retrieval alone cannot guarantee that an agent obeys a rule; the rule has to be present before the first token is generated. Total Recall stores each correction, preference and invariant as a typed node with a modality (must, should, must not) and a priority, then compiles the binding set into CLAUDE.md, AGENTS.md, GEMINI.md and their peers. The compiler writes only between its own markers, budgets each section so that no rule is silently dropped, and refuses to run from a stale copy of itself. Semantic search remains available for everything that does not need to be in context.
