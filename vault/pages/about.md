## Who I am

I am a software engineer. I build systems where the data stays with the person it belongs to: plain files, open specifications, and runtimes you can inspect, fork and carry with you.

## How I work

- **Files over databases.** A vault of Markdown with typed frontmatter can be a content system, a memory store and an API surface at once.
- **Contracts over vibes.** Writes made by AI go through validated operation envelopes, never raw file edits.
- **Publish the standard.** If a system matters, the specification ships so others can implement it without me.

## Tools

TypeScript, Node.js, Python, Postgres, Supabase, Next.js, Vercel. Agents: Claude Code, Codex.
