I am **Greg Iteen**, a systems engineer. My work addresses a structural
weakness in agentic software: state that is opaque, unvalidated and bound to
the vendor who stores it. I replace that state with typed Markdown documents,
admit every write through a deterministic operation contract, and compile what
an agent has learned into the instruction files that govern its next session.

The same foundation runs in production across two multi-tenant platforms and
is published as an open specification, a reference engine and a memory
system that any agent can adopt.
